# 📝 Smart TodoList

Клиент-серверное веб-приложение для управления задачами с возможностью добавления, удаления, отметки выполнения и фильтрации.

## 🎯 Цель проекта

Разработать клиент-серверное веб-приложение, демонстрирующее навыки работы с фронтендом, бэкендом, асинхронными запросами, тестированием и деплоем.

## 🚀 Возможности

- ✅ Добавление новых задач
- ✏️ Отметка выполнения через чекбокс
- 🗑️ Удаление задач
- 🔍 Фильтрация: **Все / Активные / Завершённые**
- 📱 Адаптивный дизайн для мобильных устройств
- 🔐 Защита API через ключ в заголовке запроса
- ⚠️ Обработка сетевых ошибок и статусов загрузки
- 🧪 Покрытие юнит-тестами (6 тестов)

## ⚙️ Установка и запуск

### Требования
- Node.js версии **18+**
- npm версии **9+**
- Git

### 1. Клонирование репозитория

```bash
git clone https://github.com/ВАШ_ЛОГИН/smart-todolist.git
cd smart-todolist
```

### 2. Запуск сервера
```bash
cd server
npm install
cp .env.example .env
```

Откройте `server/.env` и задайте свой ключ:
```
API_KEY=your-secret-key-here
PORT=3001
```

Запустите сервер:
```bash
npm run dev
```

Сервер: http://localhost:3001

### 3. Запуск клиента

Откройте новый терминал:
```bash
cd client
npm install
cp .env.example .env
```
Откройте `client/.env`:
```
VITE_API_URL=http://localhost:3001/api/tasks
VITE_API_KEY=your-secret-key-here
```
Запустите клиент:
```bash
npm run dev
```
Клиент: http://localhost:5173

### Тестирование
```bash 
cd client
npm test
```

Базовый URL: `http://localhost:3001/api/tasks`

Обязательный заголовок для всех запросов:
```
X-API-Key: <ваш ключ из .env>
```
